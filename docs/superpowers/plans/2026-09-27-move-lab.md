# Move Lab Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a "Move Lab" page where a logged-in trainer picks any two Pokémon, any move for each (unfiltered by learnset), and full pre-battle state (level/status/HP%/stat stages), runs one exchange through the real production battle engine, and inspects the exact resolved outcome — with optional RNG-forcing toggles to deterministically hit any branch (hit/miss, crit/no-crit, secondary-effect proc/no-proc).

**Architecture:** A new backend service (`movePlaygroundService.js`) builds a throwaway, fully in-memory instance of the existing `createBattleSessionService` factory (same dependency-injection seams `battleSessionService.test.js` already uses) with two synthetic Pokémon, a forced "AI" that always plays the requested move, and the **real** engine dependency (still calls the Python damage engine over HTTP) — then runs exactly one `startBattle` + `performAction` round and returns the event log. RNG-forcing is threaded through as three optional fields (`force_hit`, `force_crit`, `force_secondary`) added to the Python `BattleRequest` model and checked at each of that engine's four `random.random()` roll sites, defaulting to normal behavior when unset. A new frontend page posts to a new `/api/playground/exchange` route and renders the returned events.

**Tech Stack:** Node/Express (zod validation, mysql2/promise), Python/FastAPI + pydantic (`battle-engine/`), React (existing `v2/pages/*` pattern), `node:test` for backend tests, `pytest` for the Python engine.

**Spec:** `docs/superpowers/specs/2026-09-27-move-lab-design.md`

## Global Constraints

- No IV/EV/nature/held-item stat knobs — the engine doesn't model them (`backend/src/campaign/hydrate.js:15`'s `statAtLevel` has no individual variance). Do not add UI or backend fields for these.
- Ability is always the species' real first non-hidden ability (from `hydrate.lookupSpecies`), never freely assignable.
- Any move can be assigned to any Pokémon — no learnset filtering anywhere in this feature.
- The exchange must go through the real production engine path (`createBattleSessionService` → `battleService.calculateDamage`/`turnOrder` → the Python `battle-engine` process over HTTP). Never reimplement damage/status/turn-order logic inside the playground service.
- Every dependency injected into `createBattleSessionService` for the sandbox must be in-memory/no-op — this feature must never write to the real `trainerdb`/`pokedex` MySQL tables (species/move *reads* from the pokedex DB are fine; battle-session *writes* are not).
- All new routes require `requireAuth`, matching every other route in `backend/src/routes/`.
- New Python request fields (`force_hit`, `force_crit`, `force_secondary`) default to `None`/unset and must not change any existing test's output in `battle-engine/tests/test_combat.py`.

## Review Focus

- A single move can faint the opposing synthetic Pokémon (e.g. a high-level attacker vs. a level-1 target), which flips `session.status` to `"won"` and triggers the real win pipeline (progress completion, XP grant, coin award, reward-offer check) inside `performAction`. If any of those dependencies aren't stubbed, the sandbox call throws or touches real services. → covered in Task 3's exchange test with a guaranteed-KO setup.
- `hpPercent: 0` should mean "already fainted going in," which `startBattle` actually rejects for the player side ("All of your Pokémon have fainted") — the API must surface that as a clean 400, not a 500. → covered in Task 3.
- An unknown `pokemonId` or `moveId` (typo, out-of-range id) must 400, not crash the process with an unhandled SQL/undefined error. → covered in Task 4's route test.
- `stages` values outside −6..6, or a `status` value outside the five real major statuses plus `"Healthy"`, must be rejected by validation before they ever reach the engine. → covered in Task 4's schema test.
- Requesting the RNG overrides on a move with `no_crit` (e.g. a confusion-style typeless move, if ever exposed) or on a status move (no damage roll at all) must not throw — `force_crit`/`force_hit` are simply irrelevant/no-ops in those branches. → covered in Task 1's Python tests (forcing crit on a status move).

```python
def _hit_check(battle: BattleRequest, move_dict: dict, details: Dict[str, Any]) -> bool:
    """One accuracy roll with Gen 3 acc/eva stages. Accuracy is a 0..1 fraction."""
    if battle.force_hit is not None:
        details["hit"] = battle.force_hit
        details["forced_hit"] = True
        return battle.force_hit
    if move_dict.get("always_hit"):
        details["hit"] = True
        details["always_hit"] = True
        return True
    accuracy = move_dict.get("accuracy")
    if accuracy is None:
        details["hit"] = True
        return True
    combined_stage = clamp_stage(
        _stages(battle.attacker)["acc"] - _stages(battle.defender)["eva"]
    )
    chance = min(1.0, float(accuracy) * accuracy_stage_multiplier(combined_stage))
    hit_roll = random.random()
    details["hit_roll"] = hit_roll
    details["accuracy"] = accuracy
    details["accuracy_stage"] = combined_stage
    details["hit_chance"] = chance
    hit = hit_roll <= chance
    details["hit"] = hit
    return hit
```

```python
def _status_verdict(battle: BattleRequest, move_dict: dict, details: Dict[str, Any]) -> Optional[str]:
    """Decide whether this move statuses the defender (secondary or pure status)."""
    status = normalize_status(move_dict.get("status_effect"))
    if not status:
        return None
    if _has_major_status(battle.defender):
        details["status_blocked"] = "already_statused"
        return None
    immune_types = STATUS_TYPE_IMMUNITY.get(status, set())
    defender_types = {str(t).lower() for t in (battle.defender.types or [])}
    if immune_types & defender_types:
        details["status_blocked"] = "type_immune"
        return None
    if battle.force_secondary is not None:
        details["forced_secondary"] = battle.force_secondary
        return status if battle.force_secondary else None
    chance = move_dict.get("effect_chance")
    chance = 1.0 if chance is None else float(chance)
    roll = random.random()
    details["status_roll"] = roll
    details["status_chance"] = chance
    return status if roll < chance else None
```

```python
    changes = move_dict.get("stat_changes") or []
```

```javascript
async function listSpecies() {
	const [rows] = await getPokedexDb().query(
		`SELECT pokemon_id, name, hp, attack, defense, special_attack, special_defense, speed
     FROM Pokemon ORDER BY pokemon_id ASC`
	);
	const [typeRows] = await getPokedexDb().query(
		`SELECT pt.pokemon_id, t.name AS type_name
     FROM Pokemon_Type pt JOIN Type t ON pt.type_id = t.type_id`
	);
	const typesByPokemon = new Map();
	for (const row of typeRows) {
		const list = typesByPokemon.get(row.pokemon_id) || [];
		list.push(row.type_name);
		typesByPokemon.set(row.pokemon_id, list);
	}
	return rows.map((row) => ({
		pokemon_id: row.pokemon_id,
		name: row.name,
		hp: row.hp,
		attack: row.attack,
		defense: row.defense,
		special_attack: row.special_attack,
		special_defense: row.special_defense,
		speed: row.speed,
		types: typesByPokemon.get(row.pokemon_id) || ["Normal"],
	}));
}

async function listMoves() {
	const [rows] = await getPokedexDb().query(
		`SELECT m.move_id, m.name AS move_name, m.power, m.accuracy, m.pp, t.name AS move_type
     FROM \`Move\` m LEFT JOIN Type t ON m.type_id = t.type_id
     ORDER BY m.move_id ASC`
	);
	return rows.map((row) => ({
		move_id: row.move_id,
		name: row.move_name,
		power: row.power,
		accuracy: row.accuracy,
		pp: row.pp,
		move_type: row.move_type || "Normal",
	}));
}

async function lookupMove(moveId) {
	const [rows] = await getPokedexDb().query(
		`SELECT m.move_id, m.name AS move_name, m.power, m.accuracy, m.pp, t.name AS move_type
     FROM \`Move\` m LEFT JOIN Type t ON m.type_id = t.type_id
     WHERE m.move_id = ?`,
		[moveId]
	);
	if (!rows.length) {
		throw new CampaignError(400, `Unknown moveId ${moveId}`);
	}
	const row = rows[0];
	let accuracy = row.accuracy == null ? 1 : Number(row.accuracy);
	if (accuracy > 1) accuracy = accuracy / 100;
	return {
		move_id: row.move_id,
		name: row.move_name,
		power: row.power,
		accuracy,
		move_type: row.move_type || "Normal",
		pp: row.pp ?? null,
	};
}

async function buildMon(input) {
	let species;
	try {
		species = await lookupSpecies(input.pokemonId);
	} catch (err) {
		throw new CampaignError(400, `Unknown pokemonId ${input.pokemonId}`);
	}
	const move = await lookupMove(input.moveId);
	const level = input.level;
	const maxHp = statAtLevel(species.hp, level, true);
	const hpPercent = input.hpPercent == null ? 100 : Number(input.hpPercent);
	const currentHp = Math.max(0, Math.round((maxHp * hpPercent) / 100));
	if (currentHp <= 0) {
		throw new CampaignError(
			400,
			`${displayName(species.name)} can't battle at 0 HP — raise hpPercent above 0`
		);
	}
	const status = input.status && input.status !== "Healthy" ? input.status : null;
	return {
		id: SYNTHETIC_MON_ID,
		pokemon_id: species.pokemon_id,
		nickname: displayName(species.name),
		level,
		max_hp: maxHp,
		current_hp: currentHp,
		attack: statAtLevel(species.attack, level, false),
		defense: statAtLevel(species.defense, level, false),
		speed: statAtLevel(species.speed, level, false),
		special_atk: statAtLevel(species.special_attack, level, false),
		special_def: statAtLevel(species.special_defense, level, false),
		types: species.types.length ? species.types : ["Normal"],
		ability: species.ability ?? null,
		debugStatus: status,
		debugStages: input.stages || {},
		moves: [
			{
				move_id: move.move_id,
				name: move.name,
				power: move.power,
				accuracy: move.accuracy,
				move_type: move.move_type,
				pp: move.pp,
				status_effect: null,
				effect_chance: null,
				force_hit: input.forceHit ?? null,
				force_crit: input.forceCrit ?? null,
				force_secondary: input.forceSecondary ?? null,
			},
		],
	};
}

function buildSandboxService(monARaw, monBRaw) {
	return createBattleSessionService({
		progress: createProgressService({ store: createMemoryStore(), countBattles: () => 1 }),
		xp: createXpService({ store: createMemoryXpStore([]) }),
		wallet: createWalletService({ store: createMemoryWalletStore({ [FAKE_TRAINER_ID]: 0 }) }),
		evolution: { findLevelEvolution: async () => null },
		moveLearn: { processLevelUp: async () => ({ learned: [], pending: [] }) },
		ai: { pickMove: async (attacker) => attacker.moves[0] },
		ppStore: createMemoryPpStore(),
		hpStore: createMemoryHpStore(),
		history: createMemoryHistoryStore(),
		getPlayerParty: async () => [monARaw],
		getEnemyBattle: async () => ({
			trainerName: "Move Lab",
			pokemon: monBRaw,
			battleType: "trainer",
		}),
	});
}

async function runExchange(monAInput, monBInput) {
	const monARaw = await buildMon(monAInput);
	const monBRaw = await buildMon(monBInput);
	const service = buildSandboxService(monARaw, monBRaw);
	const { state: startState } = await service.startBattle(FAKE_TRAINER_ID, {
		level: FAKE_LEVEL,
		battleNumber: FAKE_BATTLE_NUMBER,
	});
	const { state, events } = await service.performAction(FAKE_TRAINER_ID, {
		sessionId: startState.sessionId,
		action: { type: "move", moveId: monARaw.moves[0].move_id },
	});
	return { events, log: state.log };
}

};
```

```javascript
const express = require("express");
const router = express.Router();
const { requireAuth } = require("../middleware/auth");

const movePlaygroundService = require("../services/movePlaygroundService");

// GET /api/playground/species — every species for the Move Lab pickers.
router.get("/species", requireAuth, async (req, res) => {

		const species = await movePlaygroundService.listSpecies();
		return res.json({ success: true, species });
	} catch (err) {
		console.error("Playground species error:", err.message);
		return res.status(500).json({ success: false, error: "Failed to load species" });
	}
});

// GET /api/playground/moves — every move for the Move Lab pickers.
router.get("/moves", requireAuth, async (req, res) => {
	try {
		const moves = await movePlaygroundService.listMoves();
		return res.json({ success: true, moves });
	} catch (err) {
		console.error("Playground moves error:", err.message);
		return res.status(500).json({ success: false, error: "Failed to load moves" });
	}
});

// POST /api/playground/exchange — run one move-vs-move exchange through the
// real battle engine with fully custom Pokémon setup on both sides.
router.post(
	"/exchange",
	requireAuth,
	validateBody(playgroundExchangeSchema),
	async (req, res) => {
		try {
			const result = await movePlaygroundService.runExchange(
				req.validated.monA,
				req.validated.monB
			);
			return res.json({ success: true, ...result });
		} catch (err) {
			const status = err.status || 500;
			if (status >= 500) {
				console.error("Playground exchange error:", err);
			}
			return res.status(status).json({
				success: false,
				error: err.message || "Failed to run exchange",
			});
		}
	}
);
```

```jsx
		status: "Healthy",
		hpPercent: 100,
		stages: { atk: 0, def: 0, spa: 0, spd: 0, acc: 0, eva: 0 },
		forceHit: null,
		forceCrit: null,
		forceSecondary: null,
	};

const TRI_STATE_OPTIONS = [
	{ value: "unset", label: "Normal RNG" },
	{ value: "true", label: "Force yes" },
	{ value: "false", label: "Force no" },
];

function triStateToValue(v) {
	return v === null ? "unset" : String(v);
}

function valueToTriState(s) {
	if (s === "unset") return null;
	return s === "true";
}

function MonSetupPanel({ label, mon, setMon, species, moves }) {
	const update = (patch) => setMon((prev) => ({ ...prev, ...patch }));

		setMon((prev) => ({ ...prev, stages: { ...prev.stages, [key]: value } }));

	return (

				))}
			</div>
			<div className="movelab-overrides">
				<label>
					Hit roll
					<select
						value={triStateToValue(mon.forceHit)}
						onChange={(e) => update({ forceHit: valueToTriState(e.target.value) })}

						{TRI_STATE_OPTIONS.map((opt) => (

								{opt.label}

					Crit roll

							<option key={opt.value} value={opt.value}>
								{opt.label}

					</select>
				</label>

					Secondary-effect proc

					>

								{opt.label}
							</option>
						))}
					</select>
				</label>
			</div>
		</Panel>

const MoveLabScreen = () => {
	const [species, setSpecies] = useState([]);
	const [moves, setMoves] = useState([]);
	const [monA, setMonA] = useState(defaultMon);
	const [monB, setMonB] = useState(defaultMon);
	const [result, setResult] = useState(null);
	const [error, setError] = useState("");
	const [busy, setBusy] = useState(false);

	const load = useCallback(async () => {
		setError("");
		try {
			const [speciesRes, movesRes] = await Promise.all([
				api.get("/api/playground/species"),
				api.get("/api/playground/moves"),
			]);
			setSpecies(speciesRes.data?.species || []);
			setMoves(movesRes.data?.moves || []);
		} catch (err) {
			setError(getErrorMessage(err, "Couldn't load Move Lab data"));
		}
	}, []);

	useEffect(() => {
		load();
	}, [load]);

	const canRun = useMemo(
		() => monA.pokemonId && monA.moveId && monB.pokemonId && monB.moveId,
		[monA, monB]
	);

	const runExchange = async () => {
		setBusy(true);
		setError("");
		try {
			const payload = {
				monA: { ...monA, pokemonId: Number(monA.pokemonId), moveId: Number(monA.moveId) },
				monB: { ...monB, pokemonId: Number(monB.pokemonId), moveId: Number(monB.moveId) },
			};
			const { data } = await api.post("/api/playground/exchange", payload);
			if (!data?.success) throw new Error(data?.error || "Exchange failed");
			setResult(data);
		} catch (err) {
			setError(getErrorMessage(err, "Exchange failed"));
			setResult(null);
		} finally {
			setBusy(false);
		}
	};

	return (
		<div className="movelab">
			<h2>Move Lab</h2>
			<p>Pick two Pokémon and a move for each, then run the exchange through the real battle engine.</p>
			{error && <p className="movelab-error">{error}</p>}
			<div className="movelab-panels">
				<MonSetupPanel label="Mon A" mon={monA} setMon={setMonA} species={species} moves={moves} />
				<MonSetupPanel label="Mon B" mon={monB} setMon={setMonB} species={species} moves={moves} />
			</div>
			<Button disabled={!canRun || busy} onClick={runExchange}>
				{busy ? "Running..." : "Run exchange"}
			</Button>
			{result && (
				<div className="movelab-log">
					{result.log.map((line, i) => (
						<div key={i}>{line}</div>
					))}
					<hr />
					<pre>{JSON.stringify(result.events, null, 2)}</pre>
				</div>
			)}
		</div>
	);
};

export default MoveLabScreen;
```
