# Catching Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Poké/Great/Ultra Balls and a server-rolled Gen 3 catch in wild battles, behind a `CATCH` flag.

**Architecture:** A pure catch module (formula + committed catch-rate data) is called by a new `catch` action in `battleSessionService`, modelled on `resolveItem`. A caught Pokémon is written through a new `partyService.addCaught` (party, or PC when full). Balls are catalog items; Mart stock and the starter gift are gated on the flag. The client adds a ball pocket, a catch beat and a "caught" result.

**Tech Stack:** Node/Express, mysql2, `node:test` (backend); React + Vite, `node:test` + Vitest (frontend).

**Spec:** `docs/superpowers/specs/2026-11-20-catching-design.md`

## Global Constraints

- Party cap is `MAX_PARTY = 3` (partyService); a catch with 3 in the party goes to the PC.
- Ball item ids 9 Poké Ball, 10 Great Ball, 11 Ultra Ball; category `"ball"`; `catchBonus` 1, 1.5, 2; prices 200, 600, 1200; `usableInBattle: true`, `usableOverworld: false`.
- Flag name `CATCH` (`FLAG_CATCH=1`), default off. Off: no balls in Mart stock, no starter gift, catch action → 403 "Catching isn't open yet".
- Catch only when `session.wild`; any other battle → the existing 400 "Unsupported action type".
- Status bonus ×2 slp/frz, ×1.5 par/psn/brn. Caught Pokémon stored with status "Healthy", experience 0.
- Starter gift: 5 Poké Balls.
- FireRed copy: 0 "Oh no! The Pokémon broke free!", 1 "Aww! It appeared to be caught!", 2 "Aargh! Almost had it!", 3 "Shoot! It was so close, too!", caught "Gotcha! NAME was caught!", PC "NAME was sent to the PC."
- No git commits (branch carries unrelated uncommitted work; same ruling as the PvP plan).

## Review Focus

1. A throw while the active Pokémon has fainted (`requiresSwitch`) must be refused before the ball is spent. (Task 3 test)
2. A failed throw whose enemy beat or end-of-round chip faints the wild Pokémon must end as a normal wild win (XP), not "caught" and not stuck. (Task 3 test)
3. A species missing from `catch_rates.json` must still be catchable (default rate 45), not crash. (Task 1 test)
4. A saving failure after a successful roll must refund the ball and leave the battle active. (Task 3 test)
5. With the flag off, a trainer who already owns balls sees a refusal message, not a broken battle. (Task 3 test: 403 with the ball count unchanged)

- [ ] **Step 2: Write the failing tests**

```js
it("catch rates cover the Gen 1 dex with known anchors", () => {
	const rates = require("../../data/catch_rates.json");
	assert.equal(Object.keys(rates).length, 151);
	for (const r of Object.values(rates)) assert.ok(r >= 3 && r <= 255);
	assert.deepEqual([rates[16], rates[150], rates[143]], [255, 3, 25]); // Pidgey, Mewtwo, Snorlax
});
it("unknown species fall back to 45", () => assert.equal(catchRateOf(9999), 45));
it("a = floor((3M-2H)*rate*ball/(3M)) * status", () => {
	assert.equal(catchValue({ maxHp: 100, hp: 100, rate: 45, ballBonus: 1, status: null }), 15);
	assert.equal(catchValue({ maxHp: 100, hp: 100, rate: 45, ballBonus: 1, status: "slp" }), 30);
	assert.equal(catchValue({ maxHp: 100, hp: 100, rate: 45, ballBonus: 1, status: "par" }), 22);
	assert.equal(catchValue({ maxHp: 100, hp: 1, rate: 45, ballBonus: 2, status: null }), 89);
});
it("a >= 255 catches without rolling", () => {
	const r = rollCatch({ maxHp: 40, hp: 1, rate: 255, ballBonus: 2, status: null, random: () => { throw new Error("rolled"); } });
	assert.deepEqual(r, { shakes: 3, caught: true });
});
it("four passed checks catch; shakes count passed checks, capped at 3", () => {
	const seq = (...xs) => () => xs.shift();
	const base = { maxHp: 100, hp: 50, rate: 45, ballBonus: 1, status: null };
	assert.deepEqual(rollCatch({ ...base, random: seq(0, 0, 0, 0) }), { shakes: 3, caught: true });
	assert.deepEqual(rollCatch({ ...base, random: seq(0, 0, 0.999) }), { shakes: 2, caught: false });
	assert.deepEqual(rollCatch({ ...base, random: seq(0.999) }), { shakes: 0, caught: false });
});
```

### Task 3: The `catch` battle action

**Files:**
- Modify: `backend/src/services/battleSessionService.js`
- Test: `backend/src/services/battleSessionService.test.js` (new `describe("catching")` beside "wild battles", reusing `makeService`; `makeService` forwards new deps `catchOn`, `catchRandom`, `getCatchRate`, `party`)

**Interfaces:**
- Consumes: `rollCatch`, `catchRateOf` (Task 1); `party.addCaught`, item `catchBonus` (Task 2).
- Produces: action `{ type: "catch", itemId }`; event `{ actor: "player", type: "catch", itemId, itemName, nickname, shakes, caught, inPc? }`; session status `"caught"`; response `progress: { wild: true, caught: { nickname, inPc } }`.
- New deps: `catchOn` (default flag), `catchRandom` (default `random`), `getCatchRate` (default `catchRateOf`), `party` (default `require("./partyService")`).

`resolveCatch(session, action, trainerId)` order: flag → 403 "Catching isn't open yet"; `requiresSwitch` → 400 (same text as items); item missing or category ≠ `"ball"` → 400 "That's not a Poké Ball"; `consumeItem` false → 400 "You don't have a NAME"; roll. Caught: `addCaught` (on throw: `addItem` refund best-effort, rethrow as 500 "Couldn't save the caught Pokémon"), then status `"caught"`. Not caught: one enemy beat + `endOfRoundChip` exactly as `resolveItem`. `performAction` allows `"catch"` only when `session.wild`; the `"caught"` status takes no XP/coin branch.

  2. `catchOn: () => false` → 403; ball count unchanged.
  3. Potion as the item → 400; no balls owned → 400.
  4. fainted active (`requiresSwitch`) → 400; ball count unchanged.
  5. `catchRandom: () => 0` → `state.status === "caught"`, event `{ type: "catch", caught: true, shakes: 3 }`, `addCaught` got `{ pokemon_id, level, current_hp: enemy HP, status: "Healthy", experience: 0 }` and the enemy's moves as `{ move_id, pp: current_pp }`, no `xp_gain` event, ball count −1, `result.progress.caught.nickname` set.

  8. failed throw where the enemy beat's chip faints the wild Pokémon (stub engine / poisoned enemy at 1 HP) → status `"won"` with `xp_gain`, never `"caught"`.
